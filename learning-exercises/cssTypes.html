What you'll learn: How inline, internal, and external CSS apply styles to HTML.

Try it: Edit one paragraph's style, then compare it with the class rule and linked stylesheet.

Detailed explanation: Inline, internal, and external CSS

Inline CSS is written on an element's style attribute. Internal CSS is in a style element in the document head. External CSS is in a separate file linked with a link element. The browser combines matching rules using the cascade, which considers importance, selector specificity, and source order.

Example: This page gives one paragraph a class styled by color.css, another a class styled in the page head, and a third an inline style.

Common pitfall: The three methods are not interchangeable for maintenance. Repeating inline styles makes site-wide updates difficult. When rules conflict, specificity and importance matter in addition to source order.

Three ways to add CSS
