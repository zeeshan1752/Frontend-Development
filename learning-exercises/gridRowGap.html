What you'll learn: How row and column gaps add space between grid tracks.

Try it: Adjust row-gap and column-gap independently to compare the spacing.

Detailed explanation: Grid row and column gaps

Grid gaps create consistent empty space between tracks without adding margins to each item. Row gap affects vertical spacing; column gap affects horizontal spacing. The gap shorthand can set one value for both or two values for rows then columns.

Example: Use gap: 1rem 2rem for a 1rem row gap and a 2rem column gap. Separate long and short names can make a demonstration easier to read.

Common pitfall: A gap is space between tracks, not around the outside of the grid. Add padding to the container if you also need space at its edges.

Grid row and column gaps

column-gap controls horizontal space between columns. row-gap controls vertical space between rows.
