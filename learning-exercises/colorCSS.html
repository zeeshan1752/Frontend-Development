Detailed explanation: CSS color formats

CSS colors can be written with named colors, RGB or RGBA functions, hexadecimal notation, and other formats. RGB describes red, green, and blue channel values. Hex notation encodes those channel values with hexadecimal digits. The format changes how you write the color, not how the browser paints it.

Example: A named color such as darkgreen, an RGB value such as rgb(15, 85, 160), and a hex value such as #9f1239 are all valid CSS color values.

Common pitfall: Check text contrast against its background. A syntactically valid color can still be too faint to read.
