Detailed explanation: HTML document structure

The doctype tells the browser to use modern HTML parsing. The html element contains the whole document. The head stores information and linked resources, including the title, stylesheets, and metadata. The body contains the visible page content. External CSS and JavaScript keep presentation and behavior in separate files.

Example: This lesson links tutorial.css in the head and loads tutorial.js with defer. The title appears in the browser tab; the h1 appears in the document.

Common pitfall: Visible page content belongs in the body, not the head. Relative file paths must match the real filename and location exactly.
