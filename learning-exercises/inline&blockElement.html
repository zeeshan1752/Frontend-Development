Detailed explanation: Block and inline elements

Block elements normally begin on a new line and use the available width. Inline elements flow within a line of text and take only the space their content needs. Some elements, such as inline-block elements, can sit on a line while still accepting width and height.

Example: A paragraph is block-level by default. A link or strong element is inline by default. CSS can change these behaviors with display.

Common pitfall: Do not choose an element only for its visual shape. Use HTML according to meaning, then use CSS display rules to control layout.
