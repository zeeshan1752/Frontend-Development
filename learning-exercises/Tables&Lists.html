Detailed explanation: HTML lists and tables

Use unordered lists when order does not matter and ordered lists when sequence matters. Every list item belongs inside a list. A table represents related data arranged in rows and columns. Captions describe the table, and header cells identify the meaning of each row or column.

Example: A recipe's ingredients can be an unordered list, while its steps can be an ordered list. A schedule can use a table with column headers and row headers.

Common pitfall: Do not use tables to position page content. Do not put a nested list beside a list item; nest it inside the item it describes.
