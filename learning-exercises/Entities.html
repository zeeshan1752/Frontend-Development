What you'll learn: How HTML character references display symbols such as ampersands and copyright marks.

Try it: Add a sentence containing an ampersand and a less-than sign; write each as an HTML entity.

Detailed explanation: HTML character references

Browsers parse angle brackets and ampersands as part of HTML syntax. A character reference lets you display a reserved character as visible text. The browser converts the reference while rendering the page, so readers see the symbol instead of the code used to write it.

Example: Write the less-than sign as &lt;, the greater-than sign as &gt;, and an ampersand as &amp;. You can also write named symbols such as &copy;.

Common pitfall: Do not type a raw less-than sign before text that could look like a tag. It may be interpreted as markup. Normal HTML text also collapses repeated spaces, so use CSS for spacing.

HTML character references

Some characters have a special meaning in HTML. Character references let you show those characters as text.

  • &amp; displays as & (ampersand)
  • &lt; displays as < (less-than sign)
  • &gt; displays as > (greater-than sign)
  • &copy; displays as © (copyright sign)

Browsers collapse repeated spaces in normal text. Use CSS for layout and spacing instead of invisible characters.
