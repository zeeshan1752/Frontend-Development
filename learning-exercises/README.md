# Learning exercises

This folder groups the original standalone HTML/CSS practice pages into one place. Each lesson starts with a short explanation and a Try it prompt. Expand “Detailed explanation” for a deeper concept walkthrough, a concrete example, and a common pitfall. Examples were cleaned up where unclear while retaining the topic progression through HTML structure, selectors, layout, responsive design, and visual effects.

Start at [`index.html`](index.html) for a topic-by-topic list, or open any `.html` file directly in a browser. `color.css` is shared by `cssTypes.html`. Image practice uses a local SVG illustration, so it works without an external image or a missing file.

## Topics represented

- HTML structure, entities, semantic tags, links, lists, tables, and forms
- CSS types, selectors, colors, fonts, box model, borders, shadows, and variables
- Display, positioning, floats, Flexbox, Grid, and responsive media queries
- Pseudo-selectors, transitions, transforms, and keyframe animation
- Browser developer tools and introductory page structure

The two personally addressed practice pages and the personal photo were not copied into this repository. Editor state and machine-specific configuration were also left out. A couple of file references were adjusted in this copy so the examples remain self-contained.
