What you'll learn: How visibility and stacking order affect whether and where elements appear.

Try it: Change the z-index values, then compare visibility hidden with display none.

Detailed explanation: Visibility and stacking order

Visibility hidden makes an element invisible while keeping its layout space. Display none removes the element from layout. Z-index controls stacking order for positioned elements and within stacking contexts; a larger number does not always win if the elements belong to different stacking contexts.

Example: Compare two rows where the middle element uses visibility hidden versus display none. In an overlap, increase the front element's z-index to bring it forward within the same stacking context.

Common pitfall: A negative z-index can place an element behind the page background. Use descriptive text in overlapping examples so the stacking order is easy to see.
