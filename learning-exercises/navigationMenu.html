What you'll learn: How a navigation list can be laid out with Flexbox and made keyboard accessible.

Try it: Use Tab to move through the navigation links and inspect the focus indicator.

Detailed explanation: Navigation menus

A nav element identifies a set of navigation links. A list organizes the destinations, and CSS can lay them out horizontally with Flexbox. Labels and link text should make destinations understandable. A visible focus style allows keyboard users to follow the same menu.

Example: Use <nav aria-label='Main navigation'> around a list of links. Use real fragment or page destinations so links work without JavaScript.

Common pitfall: Do not place a div directly as a child of ul; list children should be li elements. A decorative search field is not functional unless it is connected to search behavior.
