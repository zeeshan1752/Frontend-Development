What you'll learn: How labels, input types, and fieldsets make forms easier to use.

Try it: Add a labeled input and connect its label to the input with matching for and id values.

Detailed explanation: HTML forms and labels

A form groups controls that collect input. A label gives a control a readable name and can focus it when selected. Matching a label's for value to an input's id connects them. Input types provide appropriate keyboards and browser validation. Fieldsets and legends group related choices.

Example: Use type='email' for an email address and put radio buttons for one question under the same name. Give each radio a distinct value.

Common pitfall: Placeholder text is not a replacement for a label. A front-end form without a server or submit handler cannot store answers; avoid implying that it sends data.
