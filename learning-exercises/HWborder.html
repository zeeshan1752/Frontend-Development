Detailed explanation: CSS sizing, borders, and backgrounds

Width and height set an element's dimensions. A border has a width, style, and color; shorthand can set all three together. Border radius rounds corners. Background properties can set a color or image and control repetition, size, and position.

Example: Use border: 2px solid #2563eb for a complete border rule. Use background-size: cover when an image should fill a region while keeping its proportions.

Common pitfall: A unit is required for most nonzero CSS lengths, such as 700px. Give fixed-width examples a max-width or responsive rule so they do not overflow on small screens.

CSS size, borders, and backgrounds

Use width and height to size an element. Borders can use different styles on each side, and border-radius rounds the corners.
