What you'll learn: How Flexbox arranges items along a main axis and aligns them across the other axis.

Try it: Change justify-content, then change align-items and compare the two directions.

Detailed explanation: Flexbox main and cross axes

Flexbox is a one-dimensional layout model. A flex container arranges children along a main axis, which follows flex-direction. The cross axis is perpendicular. Justify-content distributes items on the main axis; align-items aligns them on the cross axis. Gap sets consistent spacing, and flex-wrap allows items to continue on another line.

Example: With the default row direction, justify-content moves items horizontally and align-items moves them vertically. Switching to column changes which direction is the main axis.

Common pitfall: Do not assume the main axis is always horizontal. It changes when flex-direction changes, and alignment settings follow the axes.

Flexbox: arrange items in one direction

A flex container has a main axis and a cross axis. With the default row direction, the main axis runs left to right and the cross axis runs top to bottom.

  • justify-content distributes items along the main axis.
  • align-items aligns items along the cross axis.
  • gap adds space between items.
