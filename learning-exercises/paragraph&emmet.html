Detailed explanation: Headings, paragraphs, and Emmet

Headings form the outline of a page. Use one clear main heading, then use lower heading levels for sections and subsections. Paragraphs group related sentences. Strong and emphasis tags indicate meaning, while line breaks are for meaningful breaks within one block of text.

Example: An editor with Emmet can expand ul>li*3 into an unordered list containing three list items. Use h2 for a section under the page's h1.

Common pitfall: Do not select heading levels because of their font size. Do not use repeated br tags to create vertical spacing; use paragraphs, margins, or padding.

Headings, paragraphs, and Emmet

Use headings to show the outline of a page. Start with one main heading, then use lower-level headings for sections and subsections.

Section heading

A paragraph contains a related block of text. Use strong for important text and emphasis when a phrase needs stress.

A line break is useful for a meaningful break, such as an address, but use a new paragraph for a new thought.

Emmet shortcut

In an editor with Emmet enabled, ul>li*3 expands to a list with three list items. Try typing that shortcut in an HTML file and expanding it.
