Detailed explanation: CSS custom properties

A custom property stores a CSS value under a name beginning with two hyphens. Define it in a rule such as :root to make it available throughout the document, then read it using var(). A fallback can be supplied if the custom property is missing. This makes theme changes and repeated values easier to manage.

Example: Set --color-accent: #f97316 once, then use var(--color-accent) for borders and highlights.

Common pitfall: A misspelled or undefined custom property makes the declaration invalid unless a fallback is supplied. Define a variable before depending on it.
