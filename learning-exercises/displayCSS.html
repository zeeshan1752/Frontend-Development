What you'll learn: How block, inline, and inline-block display values affect size and line flow.

Try it: Switch an example between inline, block, and inline-block and observe the layout.

Detailed explanation: CSS display values

The display property controls an element's outer layout behavior. Block elements start on a new line and can take available width. Inline elements flow with text and generally ignore width and height. Inline-block elements remain in line flow but accept dimensions. Flex and grid create layout contexts for their children.

Example: Change an example's display from inline to inline-block and observe that width begins to apply while the element can still share a line.

Common pitfall: Display changes layout, not semantic meaning. Keep the HTML element that fits the content, then use CSS to control its visual behavior.
