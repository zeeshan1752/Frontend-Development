What you'll learn: How CSS Grid creates columns and places items in a two-dimensional layout.

Try it: Change the minimum column width and resize the browser to see the grid adapt.

Detailed explanation: CSS Grid columns

Grid is a two-dimensional layout system: it can control rows and columns together. A grid container defines tracks, and its direct children become grid items. Repeat and fractional units make track definitions shorter. Auto-fit can create a responsive number of columns from available space.

Example: repeat(auto-fit, minmax(10rem, 1fr)) fits as many columns as possible while keeping each one at least 10rem wide.

Common pitfall: Grid rules apply to direct children of the grid container. Extra wrappers can change which elements become grid items.
