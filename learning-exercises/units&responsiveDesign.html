What you'll learn: How fixed, relative, and viewport units affect responsive sizing.

Try it: Change a width from pixels to rem or percent and compare it at different viewport sizes.

Detailed explanation: CSS units and responsive sizing

Pixels are fixed CSS lengths. Percentages are relative to a containing block. Viewport units relate to the viewport dimensions. Em is relative to the current element's font size; rem is relative to the root element's font size. Relative units can make layouts more flexible, while media queries can adapt layouts at breakpoints.

Example: A 60% width uses 60 percent of the containing block. A 1.25rem font size scales with the root font size. A 70vw width follows the viewport width.

Common pitfall: Viewport units can be wider than a content column, and fixed pixels can overflow narrow screens. Combine them with max-width, min(), or responsive rules where needed.
