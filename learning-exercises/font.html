What you'll learn: How font family, size, weight, and line spacing affect readability.

Try it: Change the font size and line height, then compare the paragraph's readability.

Detailed explanation: CSS font properties

Font family chooses the typeface; size controls the scale; weight controls thickness; style can make text italic; and line-height controls space between lines. A font stack lists preferred fonts followed by fallbacks. Relative sizes such as rem adapt to the root text size.

Example: Use a readable sans-serif stack for interface text and a monospace stack for code. Increase line-height for long paragraphs to improve scanning.

Common pitfall: If a named web font is not loaded, the browser falls back. Include a sensible fallback and do not assume every visitor has the same fonts installed.

CSS font properties

Fonts change the look and readability of text. These examples use fonts installed with common systems, so no network connection is needed.

Serif family: a traditional style with small strokes at letter ends.
Sans-serif family: a clean style, shown at a larger size.
Monospace family: each character takes a similar amount of space.

Font weight, style, size, and line height are separate properties you can adjust independently.
