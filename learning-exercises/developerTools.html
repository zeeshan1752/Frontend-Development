Detailed explanation: Browser developer tools

Developer tools provide a live view of the page's DOM, styles, network activity, and JavaScript messages. The inspector can reveal which rule wins and where a style came from. The console shows logs and errors. Responsive mode simulates different viewport sizes. Changes made there are temporary experiments.

Example: Inspect a paragraph, untick its color declaration, and watch the page update. Then copy the change into the source file if you want to keep it.

Common pitfall: A temporary edit in DevTools does not update the file on disk. Refreshing the page usually resets those changes.

Browser developer tools

Developer tools help you inspect a page and experiment while it is open. Changes made in the tools are temporary; edit the source file to keep a change.

  1. Right-click an element and choose Inspect to find its HTML.
  2. In the Styles panel, toggle a CSS declaration or change its value and see the page update.
  3. Open the Console to read messages and JavaScript errors.
  4. Use the device or responsive view to preview the page at narrower widths.
