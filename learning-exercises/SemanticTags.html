What you'll learn: How semantic elements label the purpose of page regions for people and browsers.

Try it: Replace a generic div with a header, main, article, or footer where it fits.

Detailed explanation: Semantic HTML elements

Semantic elements describe the role of a region. A header introduces a page or section; nav groups navigation links; main contains the page's primary content; article is a self-contained composition; section groups a theme; aside contains related content; footer provides closing information. These elements make page structure clearer to browsers and assistive technology.

Example: Use <main> once for the main content, then place an <article> and a related <aside> inside it. A generic <div> is still appropriate when no semantic element fits.

Common pitfall: Do not replace every div with a semantic tag. Choose the element that matches the content's role, and avoid nesting a main element inside another main element.
