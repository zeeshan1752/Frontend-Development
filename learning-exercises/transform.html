Detailed explanation: CSS transforms

Transform changes an element's visual position, scale, rotation, or skew without changing the normal flow space it occupies. Multiple transform functions can be combined in one declaration. Transform origin determines the point around which rotation and scaling occur.

Example: Use translate() to move an element, rotate() to turn it, and scale() to resize its visual appearance. The page layout still reserves the original box space.

Common pitfall: A transformed element can overlap nearby content because its original layout space remains unchanged. Keep hover movement modest and make the effect usable with keyboard focus when interaction matters.
