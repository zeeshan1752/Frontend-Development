What you'll learn: How keyframes and animation properties move an element over time.

Try it: Change a keyframe position or duration and observe how the motion changes.

Detailed explanation: CSS keyframe animation

A CSS animation applies a sequence of style changes over time. Keyframes define intermediate or start and end states. Animation duration controls one cycle, iteration count controls repetitions, and timing functions control the pace. Direction can alternate between keyframes or reverse the sequence.

Example: The move-card keyframes change transform from a starting position to an ending position. An alternate direction makes each cycle travel back.

Common pitfall: Animating layout properties such as width or top can cause extra layout work. Transform and opacity are often smoother. Respect the prefers-reduced-motion setting.
