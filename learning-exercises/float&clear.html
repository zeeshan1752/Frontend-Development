Detailed explanation: CSS float and clear

Float was designed to let text wrap around an item, often an image. A floated element moves toward the left or right edge of its containing block and surrounding inline content flows beside it. Clear prevents an element from sitting beside a float on the specified side.

Example: Set float: left on a note or image, then use clear: both on the next section to start below either side.

Common pitfall: Float is not a general replacement for modern page layout. Use Flexbox or Grid for navigation, columns, or card grids.

Float and clear

float moves an element to one side so nearby text can wrap around it. clear moves a later element below the float.
