Detailed explanation: CSS media queries

A media query conditionally applies CSS when a feature of the viewing environment matches. Width breakpoints are commonly used to adapt layouts, spacing, or typography to the available viewport. Queries can target a range or a minimum/maximum width, and non-overlapping ranges avoid conflicting states.

Example: A query such as @media (max-width: 600px) can turn a multi-column grid into one column on smaller screens.

Common pitfall: Do not target specific phone or tablet brands. Design around available space, and check that neighboring breakpoint ranges have no unintended gaps or overlaps.
