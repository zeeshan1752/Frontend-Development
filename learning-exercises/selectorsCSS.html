Detailed explanation: Element, class, id, and group selectors

Element selectors affect every matching tag. A class selector can be reused across many elements. An id selector is for one unique element. A group selector applies the same declarations to several selectors separated by commas. Selector choice determines how broadly a rule applies.

Example: The rule footer, span { color: ... } styles footer elements and spans. A rule for .second-class styles every element carrying that class.

Common pitfall: A comma creates a group of separate selectors. A space creates a descendant relationship, so footer span means a span inside a footer.
