Detailed explanation: Attribute selectors and pseudo-classes

Attribute selectors match elements by the presence or value of an HTML attribute. Pseudo-classes match a state or relationship, such as keyboard focus, hover, or a child's position. The nth-child pattern can select odd items, even items, or a repeating sequence.

Example: input[type='email'] selects email inputs. li:nth-child(odd) selects every other list item, starting with the first.

Common pitfall: A selector must match the real attribute value and document structure. Add labels to form fields; placeholder text alone is not a label.
