What you'll learn: An id names one unique element, while a class can be reused on many elements.

Try it: Give two cards the same class, then give one of them a unique id and style each selector.

Detailed explanation: IDs and classes

A class is a reusable label for one or more elements. An id is a unique label for one element in the document. CSS selects a class with a leading dot and an id with a leading hash. Classes work well for visual styles; ids are useful for unique sections and fragment links.

Example: Use .card for every card and #main-card for one specific card. An element can carry more than one class, separated by spaces.

Common pitfall: Avoid repeating the same id on multiple elements. For reusable styling, prefer a class rather than creating a different id for every item.

IDs and classes

Use a class for a style that may appear on many elements. Use an id to identify one unique element on the page.
