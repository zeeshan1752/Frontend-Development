Detailed explanation: CSS selectors

A selector describes which elements receive a CSS rule. Element selectors match tag names. Class selectors match reusable class values. Id selectors match a unique id. A descendant selector matches at any depth, while a child selector matches only direct children. An adjacent-sibling selector matches the next sibling immediately after another element.

Example: .article p selects paragraphs anywhere inside an article. .list > li selects direct list items. h2 + p selects a paragraph immediately following an h2.

Common pitfall: A selector only affects elements that actually match its structure. Keep list items inside their ul or ol so child selectors and HTML semantics both work.
