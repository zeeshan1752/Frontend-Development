Detailed explanation: CSS transitions

A transition interpolates a property from its old value to its new value when a state changes. It needs a property, duration, and optionally a timing function and delay. Hover and focus are common state changes, but transitions can also follow class changes made by JavaScript.

Example: The button changes background color and position on hover. The transition declared in its base rule animates those changes smoothly.

Common pitfall: A transition does not create a state change by itself. Set a different start or end value, and prefer listing the properties to animate instead of using all.

CSS transitions

A transition animates a property when a state changes. Hover or keyboard-focus the button. Its color, position, and shadow change over a short duration.

Transitions need a starting value and a changed value. Here, :hover supplies the changed values. The style block lists only the properties that should animate.
